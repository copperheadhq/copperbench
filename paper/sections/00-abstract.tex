Language-model agents are now evaluated extensively on software engineering, where a test suite supplies the oracle. Hardware design presents a different structure: strong deterministic checkers exist (electrical rule checks, design rule checks, netlist-to-document consistency), but there is no equivalent of a unit test that states what the change was supposed to accomplish, and an error is discovered at a fabrication run rather than at a rerun. We present \emph{copperbench}, a benchmark that evaluates agents on real KiCad projects through the copperhead agent harness, using electrical verification as a partial oracle and pairing it with end-state assertions that state what the requested change was.

The benchmark makes three commitments that we argue any agentic benchmark in this setting needs. First, grading is deterministic, offline, and model-free: reproducing a published score requires the repository but no provider credential. Second, tasks are declarative data graded by a closed assertion vocabulary, so two tasks are comparable by construction rather than by the good intentions of whoever wrote their checkers. Third, the suite contains tasks whose correct outcome is a refusal, drawn from budget arithmetic that the requested change would violate, alongside tasks with a correct edit, so that neither compliance nor caution is a winning strategy on its own.

We report strict pass rate and cost per passing task, separately per difficulty tier, along with consistency across repeats, refusal correctness, edit surgicality, and a deterministic failure taxonomy that ranks what to fix next.
